# My Portfolio Website

A professional and responsive portfolio website built for an MCA student interested in **Cloud Computing** and **Data Science**. This project is designed to showcase my skills, projects, education, certifications, and contact information.

## 🌐 Live Preview

You can host this project using **GitHub Pages**.
https://github.com/rohitatkare0/Portfolio-website.git

---

## 📌 Features

- Responsive design for desktop, tablet, and mobile
- Clean and modern UI
- About Me section
- Skills section
- Projects showcase
- Education details
- Contact section
- Smooth scrolling navigation
- Easy to customize

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
